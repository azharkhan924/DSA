## 🧠 How to Use These Notes

1. **Read the problem statement** and try to solve it yourself first.
2. **Check the approach** — understand the intuition before looking at code.
3. **Compare multiple approaches** — most problems have brute force + optimized solutions.
4. **Note the complexity** — every solution includes Time & Space complexity.
