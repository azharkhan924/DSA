Length of the longest subarray with zero Sum
Problem Statement: Given an array containing both positive and negative integers, we have to find the length of the longest subarray with the sum of all elements equal to zero.

Example:
Input: arr = [15, -2, 2, -8, 1, 7, 10, 23]
Output: 5
Explanation: The longest subarray with sum 0 is [-2, 2, -8, 1, 7] with length 5.


Approach 1: Brute Force (O(n^2))
Generate all possible subarrays and calculate their sum. Track the maximum length where sum is 0.

class Solution {
    public int maxLen(int[] arr) {
        int maxLen = 0;
        int n = arr.length;
        for (int i = 0; i < n; i++) {
            int sum = 0;
            for (int j = i; j < n; j++) {
                sum += arr[j];
                if (sum == 0) {
                    maxLen = Math.max(maxLen, j - i + 1);
                }
            }
        }
        return maxLen;
    }
}


Approach 2: Optimal - Prefix Sum with HashMap (O(n))

Algorithm:
1. Initialize a variable sum = 0 to store the running prefix sum, and maxLength = 0 to store the maximum length found so far.
2. Seed HashMap with (0, -1) to handle subarrays starting at index 0 whose sum equals 0 (or explicitly check if sum == 0 -> maxLen = i + 1).
3. Traverse the array and add current element to prefixSum.
4. If prefixSum is already in the HashMap, it means the subarray between the previous occurrence and the current index has a sum of 0. Update maxLength = max(maxLength, current_index - m.get(prefixSum)).
5. If prefixSum is NOT in the HashMap, store (prefixSum, current_index). We only store the first occurrence to maximize the subarray length.
6. Return maxLength.

import java.util.HashMap;

class Solution {
    public int maxLen(int[] arr) {
        HashMap<Integer, Integer> m = new HashMap<>();
        m.put(0, -1); // Handles cases where prefixSum itself becomes 0
        int prefixSum = 0;
        int maxLength = 0; // Default to 0 if no 0-sum subarray is found
        for (int i = 0; i < arr.length; i++) {
            prefixSum += arr[i];
            if (m.containsKey(prefixSum)) { 
                maxLength = Math.max(maxLength, i - m.get(prefixSum));
            } else {
                m.put(prefixSum, i);
            }
        }

        return maxLength;
    }
}

Count subarrays with given xor K

Given an array of integers nums and an integer k, return the total number of subarrays whose XOR equals to k.

Example 1:
Input : nums = [4, 2, 2, 6, 4], k = 6
Output : 4
Explanation : The subarrays having XOR of their elements as 6 are [4, 2], [4, 2, 2, 6, 4], [2, 2, 6], and [6].


Approach 1: Brute Force (O(n^3))
Check all possible subarrays and compute their XOR using 3 nested loops.

int count = 0;
int n = nums.length;
for (int i = 0; i < n; i++) {
    for (int j = i; j < n; j++) {
        int xor = 0;
        for (int k1 = i; k1 <= j; k1++) {
            xor ^= nums[k1];
        }
        if (xor == k) {
            count++;
        }
    }
}


Approach 2: Better Solution (O(n^2))
Compute the running XOR in the inner loop, eliminating the third loop.

int count = 0;
int n = nums.length;
for (int i = 0; i < n; i++) {
    int xor = 0;
    for (int j = i; j < n; j++) {
        xor ^= nums[j];
        if (xor == k) {
            count++;
        }
    }
}


Approach 3: Optimal - Prefix XOR with HashMap (O(n))

Intuition:
If prefix XOR up to index i is XR, and a subarray ending at i has XOR = k,
then the prefix XOR up to some previous index must be x such that:
x ^ k = XR  ==>  x = XR ^ k

Algorithm:
1. Initialize a hashmap to store the frequency of each prefix XOR seen so far.
2. Seed the map with (0, 1) to account for subarrays starting at index 0 whose XOR is k.
3. Keep running prefix XOR and total count initialized to 0.
4. For each element, update running xor ^= nums[i].
5. Compute required previous prefix XOR: r = xor ^ k.
6. If r exists in the map, add its frequency to count.
7. Update the map with the current prefix XOR count: m.put(xor, m.getOrDefault(xor, 0) + 1).
8. Return count.

import java.util.HashMap;

class Solution {
    public int subarraysWithXorK(int[] nums, int k) {
        int xor = 0;
        int count = 0;
        HashMap<Integer, Integer> m = new HashMap<>();
        m.put(0, 1);
        for (int i = 0; i < nums.length; i++) {
            xor ^= nums[i];
            int r = xor ^ k;
            if (m.containsKey(r)) {
                count += m.get(r);
            }
            m.put(xor, m.getOrDefault(xor, 0) + 1);
        }

        return count;
    }
}

Merge Overlapping Subintervals (LeetCode 56)

Problem Statement: Given an array of intervals where intervals[i] = [start_i, end_i], merge all overlapping intervals, and return an array of the non-overlapping intervals that cover all the intervals in the input.

Example 1:
Input: intervals = [[1,3],[2,6],[8,10],[15,18]]
Output: [[1,6],[8,10],[15,18]]
Explanation: Since intervals [1,3] and [2,6] overlap, merge them into [1,6].

Example 2:
Input: intervals = [[1,4],[4,5]]
Output: [[1,5]]
Explanation: Intervals [1,4] and [4,5] are considered overlapping.


Approach 1: Brute Force (O(n log n) + O(2n))
1. Sort the given intervals based on their start times.
2. For each interval i:
   - Check if it is already part of the last merged interval. If yes, continue to next.
   - Set start = intervals[i][0] and end = intervals[i][1].
   - Traverse the subsequent intervals j from i + 1 to n - 1:
     - If intervals[j][0] <= end: update end = Math.max(end, intervals[j][1]).
     - Else: break (since the array is sorted, remaining intervals won't overlap).
   - Add [start, end] to the result list.

import java.util.*;

class Solution {
    public int[][] merge(int[][] intervals) {
        int n = intervals.length;
        if (n <= 1) return intervals;

        // Sort by start time
        Arrays.sort(intervals, (a, b) -> Integer.compare(a[0], b[0]));

        List<int[]> ans = new ArrayList<>();

        for (int i = 0; i < n; i++) {
            int start = intervals[i][0];
            int end = intervals[i][1];

            // If already merged in previous step, skip
            if (!ans.isEmpty() && end <= ans.get(ans.size() - 1)[1]) {
                continue;
            }

            // Check remaining intervals for overlap
            for (int j = i + 1; j < n; j++) {
                if (intervals[j][0] <= end) {
                    end = Math.max(end, intervals[j][1]);
                } else {
                    break;
                }
            }
            ans.add(new int[]{start, end});
        }

        return ans.toArray(new int[ans.size()][]);
    }
}


Approach 2: Optimal - Linear Scan with List (O(n log n) + O(n))

Algorithm:
1. Sort intervals by start time in ascending order.
2. Maintain a dynamic list res of merged intervals.
3. Iterate through each interval:
   - If res is empty OR current interval start > last merged interval end:
     Add current interval as a new entry.
   - Else (overlap detected):
     Update last merged interval's end = Math.max(last merged interval end, current interval end).
4. Convert res to 2D array and return.

import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

class Solution {
    public int[][] merge(int[][] intervals) {
        // Edge case
        if (intervals.length <= 1) return intervals;

        // 1. Sort intervals by start time
        Arrays.sort(intervals, (a, b) -> Integer.compare(a[0], b[0]));

        // 2. Use a List to collect merged intervals dynamically
        List<int[]> res = new ArrayList<>();

        for (int[] curr : intervals) {
            // If list is empty OR curr does not overlap with last interval
            if (res.isEmpty() || res.get(res.size() - 1)[1] < curr[0]) {
                res.add(curr);
            } 
            // Overlapping: expand the end time of the last interval
            else {
                res.get(res.size() - 1)[1] = Math.max(res.get(res.size() - 1)[1], curr[1]);
            }
        }

        // 3. Convert List<int[]> back to int[][]
        return res.toArray(new int[res.size()][]);
    }
}
